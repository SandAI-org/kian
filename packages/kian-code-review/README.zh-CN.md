# Kian Review

轻量 VS Code 分支／提交审阅扩展。先只展示文件路径和增删统计，点击文件时才打开**一个原生只读 diff**。不用多文件长页面、不启动网页服务、不 fetch／checkout／stage／commit。

## 使用

打开源代码管理（`Cmd+Shift+G`），找到 **Kian Review**；也可以从命令面板运行 **Kian Review：显示代码审阅**。工具栏提供比较分支、查看提交、刷新和筛选；多仓库时显式选择仓库。

- **比较分支**：选择基准和对比分支，再选“分支顶端”（两版本的全部差异）或“PR／共同祖先”（祖先到对比版本的修改）。支持本地／远程分支、标签、自定义提交。远程引用以最近 fetch 为准，扩展不自动联网更新。
- **查看提交**：选择近期提交、加载更早提交或手动输入版本。初始提交与空版本比较，合并提交明确与**第一父提交**比较，不是 combined diff。
- 文件夹默认折叠，按需展开；工具栏也支持折叠文件树。这不会创建 diff 编辑器。
- 点击文件用预览标签打开单文件 diff，双击编辑器标签可固定保留。悬停文件行点击复制按钮，复制仓库相对路径；右键可复制绝对路径或打开工作区文件。删除文件也能复制路径；重命名文件复制新路径，悬停提示保留旧路径。
- 刷新才重新解析分支。每次比较固定到提交 hash，分支移动不会悄悄改变已打开的 diff。
- 不包含工作区未提交／未跟踪改动。“打开工作区文件”打开当前 checkout 的版本，可能不同于审阅版本。

## 语言支持与边界

历史文件复用 Git 内置扩展的 `git:` 文档和原生 diff。继续沿用语法高亮及现有语言支持；Pylance 虚拟文档能力取决于版本／设置，跨文件跳转可能使用当前工作区，不能保证历史语义环境隔离。

二进制沿用 VS Code 原生 diff 行为，不转为自定义文本；子模块不递归展开比较。单个超大文件仍可能慢，这里减少的是同时创建多个 diff 的负担。Git 操作超时30秒、元数据上限32MiB。只支持受信任且实际落盘的 Git workspace；不使用实验接口。

## 开发与打包

无运行时 npm 依赖、无编译步骤。执行 `node --test test/git.test.js`。`test/extension-host.js` 提供 Extension Host 测试入口，使用临时 main/feature 仓库及 demo.py／added.py／removed.py fixture，核对按需打开、剪贴板、新增／删除空侧及 Git 状态不变；在独立 user-data／extensions 目录运行。

使用 `vsce package --no-dependencies` 打包，通过“扩展：从 VSIX 安装”安装。SSH／Dev Container 必须安装在远程环境，Git 与文件读取才会发生在对应机器；若提示 Reload，只重载该窗口。

源码在 Kian 维护；VSIX 和原始测试日志不入 Git。
